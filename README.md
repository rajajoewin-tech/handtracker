# AI Magic Drawing

An interactive AI-powered drawing application
using hand gestures and computer vision.

## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- Pygame

## Features

- Real-time hand tracking
- Gesture recognition
- Air drawing
- Purple magical aura
- Particle effects
- Animated portal
- Lightning effects

## Installation

Create a virtual environment:

python -m venv .venv

Activate:

.venv\Scripts\Activate.ps1

Install dependencies:

pip install -r requirements.txt

## Run

python main.py

## Controls

ESC - Exit application
